# Maze Robot

An Arduino-based maze-solving robot designed to navigate a maze using ultrasonic distance sensors and motion control.

## Project Overview

This project focuses on building and programming a maze-solving robot. The robot uses distance sensors to detect walls, an MPU6050 sensor to measure rotation, and motor control to navigate the maze.

The project is currently under development.

## Hardware Components

* Arduino Nano
* L298N Motor Driver
* 3 Ultrasonic Sensors
* MPU6050 Gyroscope and Accelerometer
* DC Gear Motors
* Battery and Power Supply Circuit
* Robot Chassis

## Features

* Wall detection using ultrasonic sensors
* 90-degree turning using MPU6050 feedback
* Straight-line movement control
* PID-based motion control
* Maze exploration and cell mapping — under development

## Software

* Arduino IDE
* Git and GitHub for version control
